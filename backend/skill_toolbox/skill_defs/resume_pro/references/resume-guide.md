# 简历写作规范（精简版）

依据资深简历优化指南整理，用于 resume_pro 抽取与组织字段内容。

## 1. 个人信息

- **姓名**：真实姓名，不用昵称/网名；字号可大于正文，放最显眼位置。
- **年龄**：一般不写，应届生或岗位要求时写「年龄：xx 岁」。
- **身高体重**：隐私信息，除非岗位要求，否则不写。
- **证件照**：专业照片、蓝底、正装；非外企放照片，外企不放。
- **电话**：常用有效号码；格式易读（如 138 0000 8000）。
- **邮箱**：专业命名（zhangsan@qq.com 优于 123456@qq.com）。
- **地址**：城市 + 省份即可，详细地址视情况。
- **求职目标**：明确岗位，避免模糊。错误：开发工程师；正确：Java 后端开发工程师。
- **目标薪资**：多投企业 / 薪资区间大 / 更在意平台时建议不填。

## 2. 教育背景

- 学校写全名；名校可加修饰（985、211、双一流）。
- 明确学历（本科/硕士/博士）；时间用「2019年9月-2023年6月」；未毕业写预期。
- GPA 高才写，格式如「GPA：3.8/4.0（专业 top 5%）」。
- 应届生可列相关课程；有工作经验者不列。
- 荣誉证书只列有含金量的（国奖、CET-6、ACM 奖）。
- **多个教育背景按时间倒序，学历最高在最上**；适当用分隔线/空行，重要信息加粗。

## 3. 工作经历

- 换位思考，以企业用人角度描述；把描述包装成个人亮点。
- **做了什么 + 怎么做 + 做的怎样**；以数据量化成果（销售额 +20%、满意度 95%）。
- 按应聘职位选最相关内容，使用职位描述中的关键词（利于 ATS 筛选）。
- 空窗期简要解释；时间连续无空白/重叠。
- 简洁，避免重复；**倒序**（最近在前）；大厂/独角兽可加修饰语。

## 4. 项目经历

- 项目名称用实际名，晦涩时加备注；列起止日期（进行中写「至今」）。
- 项目概述 1-2 句：背景、目标、意义、规模（人数/预算/周期）。
- 明确个人角色与职责；突出贡献与团队合作。
- 关键成果量化（完成数量、提升比例、节省成本）。

## 5. 语言 / 技能 / 证书 / 兴趣爱好

- **语言**：标准水平描述（母语/流利/熟练/中级/初级），列证书（CET-6、托福、雅思），简述实际应用场景。
- **技能**：按目标岗位列相关技能，专业名词不可写错（如「熟练掌握 Java、Python、C++，熟悉 Linux、MySQL」）。
- **证书**：按岗位列（PMP、CFA、CPA、CET-6、计算机二级）。
- **兴趣爱好**：展示个性且贴合岗位（程序员写逛技术博客/开源项目；设计写看展/收藏）。
- 所有信息真实，可适当美化但不可虚构。

## 6. 作品集

- 用于证明专业水平：项目/文章/设计/代码，可链接/二维码/附件。
- 方便 HR 查看，不可放在需要会员才能下载的地方。

## 7. 自我评价

- **简短有力**：一般 3-5 句内。
- 突出核心优势：专业技能 + 软技能（沟通/协作/领导）。
- 简述职业目标与对岗位的热情、与公司的匹配。
- 避免空洞词汇（「努力工作」「有责任心」），要具体。
- 适当展示个性，避免千篇一律的模板化语言。

## 8. 呈现形式

- 简历以 **PDF** 为主（格式不因系统变化）；docx 供可编辑需求。
- 模板用简洁流式（从上至下），避免花哨；**板块分隔要明显**，勿杂糅。
- 简历命名：`姓名_应聘岗位_工作年限`（如 张三_后端开发工程师_3年）。
