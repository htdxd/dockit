# 公文版式（GB/T 9704-2012）

党政机关公文格式国家标准，**严格参数**，不是建议。来源：MiniMax cjk_typography（MIT）与 Z.AI 场景规则。

## 页面设置

| 参数 | 值 | OpenXML |
|---|---|---|
| 纸张 | A4 210×297mm | 宽 11906 twips / 高 16838 |
| 上边距 | 37mm | 2098 twips |
| 下边距 | 35mm | 1984 twips |
| 左边距 | 28mm | 1588 twips |
| 右边距 | 26mm | 1474 twips |
| 每行字数 | 28 | — |
| 每页行数 | 22 | — |
| 行距 | 固定 28pt | `line=560, lineRule=exact` |

## 字体字号表

| 元素 | 字体 | 字号 |
|---|---|---|
| 标题 | 小标宋 (FZXiaoBiaoSong-B05S) | 二号 22pt |
| 一级标题 | 黑体 SimHei | 三号 16pt |
| 二级标题 | 楷体_GB2312 | 三号 16pt |
| 三级标题 | 仿宋_GB2312 加粗 | 三号 16pt |
| 正文 | 仿宋_GB2312 | 三号 16pt |
| 附注/页码 | 宋体 SimSun | 四号 14pt |

**回退**：小标宋在无字重时回退 SimHei；`_GB2312` 系回退对应基础字体（仿宋/楷体）。

## 结构

```
┌─────────────────────────────┐
│ 发文机关标志（红头）           │ 小标宋或红色大字
│ ════════════════ (红线)      │ #FF0000 2pt
│ 发文字号: X机发〔2025〕X号     │ 仿宋三号 居中
│  标题                        │ 小标宋二号 居中，回行居中
│ 主送机关:                     │ 仿宋三号
│  正文 ...                     │ 仿宋_GB2312 三号
│ 一、一级标题                   │ 黑体三号 无缩进
│ （一）二级标题                 │ 楷体三号 缩进 2 字
│ 1. 三级标题                   │ 仿宋三号 加粗 缩进 2 字
│ (1) 四级标题                  │ 仿宋三号 缩进 2 字
│ 附件: 1. xxx                 │ 仿宋三号
│ 发文机关署名                   │ 仿宋三号
│ 成文日期                       │ 仿宋三号 中文小写数字
├─────────────────────────────┤
│ ════════════════ (版记线)     │
│ 抄送: xxx                    │ 仿宋四号
│ 印发机关及日期                  │ 仿宋四号
└─────────────────────────────┘
```

## 序号体系

```
一、     黑体    无缩进
（一）   楷体    缩进 2 字
1.      仿宋加粗 缩进 2 字
(1)     仿宋    缩进 2 字
```

## 颜色

| 元素 | 颜色 |
|---|---|
| 全部正文 | 纯黑 #000000（强制） |
| 红头 | #FF0000（强制） |
| 红线/版记线 | #FF0000 |

## 页码

- 位置：底部居中；格式 `-X-`（宋体四号）；封面无页码。
- footer 域指令：`PAGE \* arabic`（`-` 字符放在域前后 run 中，域本身只有数字）。
- 版记页不加页码（如适用）。

## 实现要点（build_docx 落到 oxml）

- 标题样式 `GongWenTitle`：`w:rFonts eastAsia="FZXiaoBiaoSong-B05S"` + `sz=44`（22pt×2）+ 居中 + `line=560 exact`。
- 正文样式 `GongWenBody`：`eastAsia="FangSong_GB2312"` + `ascii="FangSong_GB2312"` + `sz=32` + `line=560 exact`。
- 序号标题：直接在 pPr 里设 rPr（黑体/楷体/加粗），**不用** Word 自动编号（公文的序号是版式的一部分，自动编号会破坏回行对齐）。
- 红线：空段 `w:pBdr bottom`，`sz=8`(2pt) 单线 #FF0000。
