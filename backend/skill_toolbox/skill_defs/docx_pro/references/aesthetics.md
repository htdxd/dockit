# 美学配方（封面 + 场景版式）

从 Z.AI document-skills 的 7 个验证配方（R1–R7）与 MiniMax 的 13 套美学配方（MIT）中提炼，供 `build_docx.py` 的封面与场景版式使用。**封面代码必须从配方出发，禁止自由发挥。**

## 封面配方（R1–R7 结构共性）

所有配方共享同一结构骨架（差异仅在配色与元素排布）：

```
┌──────────────────────────────────────────────┐
│ 最外层表格：1 行 1 列，行高 16838 twips EXACT │
│ 全 6 边边框显式 nil（none）                    │
│ 左右/上下边距均为 0（封面节）                  │
│                                              │
│   [内层内容单元格（可再嵌一个表）]              │
│   padding-left/right 约 1134 twips           │
│                                              │
└──────────────────────────────────────────────┘
```

| 配方 | 用途 | 配色要点 |
|---|---|---|
| R1 | 纯文字封面（报告/提案） | 主色标题 + 灰副题 + 信息区，Morandi 低饱和 |
| R2 | 深色底封面（发布会/白皮书） | 深底 `#1e3a8a` 系，**文字必设白字** |
| R3 | 学术封面 | 白底 + 黑字 + 红线/校名区，宋体 |
| R4 | 公文红头 | 见 `gongwen.md`（GB/T 9704） |
| R5 | 简历封面 | 极简，无表格边框 |
| R6 | 合同封面 | 白底黑字 + 下边框线，楷体/宋体 |
| R7 | 课程/作业封面 | 顶部校徽占位 + 居中标题 |

### 封面结构规则（全部配方）

1. **封面节四边距 = 0**；节类型 NEXT_PAGE。
2. **标题字号动态计算**（calcTitleLayout）：从偏好 pt 开始，每次减 2pt，直到标题 ≤3 行；下限 24pt。CJK 行宽估算：字符数 × (pt × 20) twips ≤ 可用宽度。
3. **行高**：字号 pt 对应行高 `ceil(pt × 23)` twips，`rule=atLeast`（继承行高会裁掉大字顶部）。
4. **垂直留白**（calcCoverSpacing）：用 `spacing.before` 控制，绝不用 margin 内撑；底部保留 `spacing.before ≥ 800` twips 防止页码溢出。
5. **深/彩色底上的文字**：每条 TextRun 显式 `color`（默认黑在深底不可见）。
6. **装饰线**：用段落下边框（`w:pBdr`），**禁止** `───` 字符划线（引擎宽度不定）。
7. 标题断行在语义边界（标点/连接词后），末行 ≤2 字并入上一行（防孤字）。
8. 封面节尾部无多余分页符/空段。

## 场景版式配方（常用子集）

### Corporate 商务（standard 默认）
- 标题：Calibri/Segoe 加粗；正文 Calibri 11pt，行距 1.15–1.5×。
- 强调色：一个 accent（如 `#1F4E79`）用于表头/标题点缀，不彩虹。
- 封面：R1 或 R2。

### Academic 学术
- 中文：标题黑体、正文宋体小四(12pt)；西文 Times New Roman。
- 行距 1.3×；段前段后 0；首行缩进 2 字。
- 公式居中编号右对齐（制表位实现）；图注"图 1：..."居中 五号，表注"表 1 ..."居左。
- 封面：R3。

### Minimal 简约（简历/信函）
- 一种正文字体 + 一种 accent；无封面表格边框。
- 行距 1.15×；四周 margin 2cm。
- 封面：R5/R6。

### 公文 Gongwen
- 完整 GB/T 9704 见 `references/gongwen.md`；封面 R4。

```
强调   #c2410c (赭)    背景底 #f8fafc (近白)
深底   #0f172a → 白字  表头底 #dbeafe (浅蓝)
```

## 选择函数

- 封面：`select_cover(doc_type)` → R1 商务报告 / R2 白皮书发布 / R3 学术论文 / R4 公文 / R5 简历 / R6 合同 / R7 课程作业。
- 配色：`palette(scene)` → 按场景返回上述配色；图表情色从 `palette.accent` 派生（见 `references/chart-templates.md` 思路）。
